# DSkiller (v1.0.0)

一个 100% 纯 Swift 开发的高颜值、超轻量的 macOS 菜单栏小工具，致力于在后台实时、无感地自动清除指定目录及其子目录中的 `.DS_Store` 垃圾文件。

无需任何外部依赖（不需要 Python，也不需要 `fswatch`），开箱即用，单文件原生编译，仅需极简系统权限。

---

## ✨ 核心特性

- **🚀 100% 纯 Swift 原生开发**：无外部依赖、无脚本注入、体积超轻量（编译后仅数百KB），CPU/内存占用微乎其微。
- **🟢 动态监控状态指示**：菜单栏第一项可实时显示工作状态（绿色表示正在监听，红色表示已暂停），一目了然。
- **🎛️ 监听目录一键整合管理**：在“监听目录管理”子菜单中整合了添加新监听目录、移除已有监听目录、在 Finder 中一键打开目录等所有功能，简单清爽。
- **⏱️ 拖动滑块自定义扫描间隔**：内置优雅的滑动条（NSSlider），支持 10 秒到 1 分钟自由拖拽微调，精细化掌控扫描频率。
- **🔒 安全可信赖的 FDA 状态检测**：准确进行 Full Disk Access (完全磁盘访问权限) 运行时动态探针检测，并在界面中实时展示“🟢 已授予”或“🔴 未授予 (点击修复)”状态，而非硬编码提示语。
- **📝 实时日志及清空功能**：内置日志查看窗口，秒级滚动刷新。新增“清空日志”按钮，一键将本地日志 truncate 归零，保持系统整洁。
- **🔌 开机自启动支持**：内置 LaunchAgent 的自动注册与管理，完美适配开机自启动。
- **📦 标准 DMG 拖拽安装**：双击即可拖入 `/Applications`，本地完全不留任何散装二进制或 loose `.app` 文件夹。

## 🛠️ 构建与编译

若要从源码自行编译生成 DMG 安装包，请在终端执行以下步骤：

1. 克隆或下载本项目至本地。
2. 进入编译目录：
   ```bash
   cd menubar-app
   ```
3. 运行编译与打包脚本：
   ```bash
   ./build_app.sh
   ./build_dmg.sh
   ```
   - `build_app.sh` 将会把 Swift 源码编译为原生 `DSkiller.app`；
   - `build_dmg.sh` 将自动使用 macOS 系统的 `hdiutil` 将 app 打包为高压缩率的 `DSkiller-1.0.0.dmg`，并在打包完成后**自动清除本地 `.app` 临时文件夹**（满足“不留app”的干净工作区标准）。

## 📥 安装与使用指南

1. 双击打开项目根目录下的 `DSkiller-1.0.0.dmg`。
2. 将 **DSkiller** 图标拖拽到右侧的 **Applications**（应用程序）文件夹中。
3. 在应用程序中双击启动 **DSkiller**，它将常驻于你的 macOS 系统菜单栏中。
4. **授予完全磁盘访问权限 (FDA)**:
   - 由于 macOS 安全机制，后台扫描桌面 (Desktop) 或文档 (Documents) 需要 FDA 权限。
   - 点击 DSkiller 菜单 -> `系统权限与依赖状态` -> `如何授予完全磁盘访问权限 (FDA)...`。
   - 在系统“完全磁盘访问权限”设置中，将 `DSkiller` 勾选启用即可。

## 📂 核心路径

- **配置文件**:
  ```text
  ~/Library/Application Support/DSkiller/config.json
  ```
- **日志文件**:
  ```text
  ~/Library/Logs/dskiller.log
  ~/Library/Logs/dskiller.err.log
  ```
